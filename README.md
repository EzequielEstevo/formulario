# 🚀 Formulário Moderno & Premium

Este é um projeto de formulário de contato altamente interativo, desenvolvido com foco em **Design Premium**, **Experiência do Usuário (UX)** e **Performance**.

![Preview do Projeto](img/image.png)

## ✨ Funcionalidades

- **Design Glassmorphism**: Interface moderna com efeitos de desfoque e transparência.
- **Micro-animações**: Feedback visual suave em campos de entrada, botões e na foto de perfil.
- **Feedback de Envio Realista**: 
  - Botão com estado de carregamento (spinner).
  - Simulação de envio para API.
  - Mensagem de sucesso animada.
- **Responsividade Total**: O formulário se adapta perfeitamente a dispositivos móveis e desktops.
- **SEO & Semântica**: Estruturado com HTML5 semântico para melhor acessibilidade e rankeamento.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica.
- **CSS3 (Vanilla)**: Design system customizado, CSS Variables, Flexbox e Keyframe animations.
- **JavaScript (ES6+)**: Lógica assíncrona, manipulação de DOM e animações de estado.
- **Google Fonts**: Tipografia "Outfit" para um visual moderno.

## 📁 Estrutura do Projeto

```
/
├── index.html      # Estrutura principal e SEO
├── index.css       # Estilos, animações e design system
├── mecanic.js      # Lógica de interatividade e envio
└── img/            # Ativos visuais (avatar, background)
    ├── image.png   # Foto de perfil
    └── bg.png      # Fundo abstrato
```

## 🚀 Como Executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Preencha os campos e teste o fluxo de envio!
